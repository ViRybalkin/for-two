# На двоих

Новое мобильное PWA для общей кладовой, меню и покупок пары. Интерфейс полностью на русском и рассчитан прежде всего на iPhone шириной 320–430 px.

## Что работает в первой поставке

- пять основных разделов: Сегодня, Запасы, Меню, Покупки и Ещё;
- добавление продукта вручную и подготовленные потоки фото/чека;
- изменение количества запасов и фильтрация по месту хранения;
- генерация редактируемого демо-меню из запасов или магазинов;
- отдельные списки Tops и Makro с прогрессом и суммами;
- экран рецепта с порциями, ингредиентами, питательной ценностью и оценками;
- настройки кухни и оборудования;
- сохранение демо-данных на устройстве;
- PWA manifest и standalone-режим;
- безопасные server-only клиенты Supabase/OpenAI и начальная PostgreSQL-схема.
- реальный Responses API со Structured Outputs для меню при наличии ключа;
- точечный поиск товаров только по официальным доменам `tops.co.th` и `makro.pro`;
- server-only API запасов с транзакционными RPC-функциями Supabase.

Без настроенных секретов приложение работает в демонстрационном режиме. Подключение production-данных не требует менять интерфейс.

## Локальный запуск

Требуется Node.js 20.9+.

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

## Проверка

```bash
npm run typecheck
npm run build
```

## Supabase

1. Создайте проект Supabase.
2. Выполните по порядку `supabase/migrations/001_initial.sql` и `supabase/migrations/002_inventory_rpc.sql`.
3. Выполните `supabase/migrations/003_meal_images_bucket.sql`: миграция создаст приватный bucket `meal-images`. Сервер также создаёт его автоматически при первой генерации для уже развёрнутых проектов.
4. Добавьте `SUPABASE_URL` и `SUPABASE_SECRET_KEY` только в server-side environment Vercel.

RLS включён, публичные политики намеренно отсутствуют: браузер не получает прямой доступ к данным.

## Переменные окружения

Создайте локальный `.env.local` по образцу `.env.example`. Не добавляйте его в Git и не используйте префикс `NEXT_PUBLIC_` для секретов.

После заполнения перезапустите `npm run dev`. Проверить подключение можно через:

- `GET /api/inventory` — `source: supabase`;
- `POST /api/meal-plans/generate` — `source: openai`;
- `GET /api/catalog/search?q=jasmine%20rice&store=all` — `source: official_pages`.

## Vercel

Импортируйте эту папку как отдельный проект, добавьте переменные из `.env.example` и выполните production deploy. Ключи без префикса `NEXT_PUBLIC_` не попадут в клиентскую сборку.

## Сгенерированный визуальный материал

После подтверждения меню изображения блюд асинхронно создаются моделью из `OPENAI_IMAGE_MODEL`, сохраняются в приватном Supabase Storage и переиспользуются для неизменённой версии рецепта.
